## repalis auth login

Sign in to Repalis through your browser

```bash
repalis auth login [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--sandbox` | `boolean` | Use the sandbox environment |
| `--production` | `boolean` | Use the production environment |
| `--new-session` | `boolean` | Sign in again even if a session is already saved |

**Examples**

Choose sandbox or production, then sign in
```bash
repalis auth login
```

Sign in to sandbox
```bash
repalis auth login --sandbox
```

Sign in to production again, replacing the saved session
```bash
repalis auth login --production --new-session
```

Without a browser, e.g. in CI or as an agent, skip login and use an access token
```bash
export REPALIS_ACCESS_TOKEN=<token> REPALIS_ENVIRONMENT=sandbox
```

## repalis auth org

Choose the active organization

```bash
repalis auth org [flags] [<organization>]
```

**Arguments**

| Argument | Type | Description |
| --- | --- | --- |
| `organization` | `string` | Organization ID or slug. Omit to pick from a list (optional) |

**Examples**

Pick the active organization from a list
```bash
repalis auth org
```

Set it by slug or ID, for scripts and agents
```bash
repalis auth org acme
```

## repalis auth token

Give your app its own organization access token: a human approves it in the browser, with any --scope preselected, and the CLI prints it

```bash
repalis auth token [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--scope` | `string` | Scope to preselect on the token page, e.g. products:read. Repeatable |
| `--org` | `string` | Organization ID or slug for this invocation only |

**Examples**

Add a token for the active organization to .env.local
```bash
echo "REPALIS_ACCESS_TOKEN=$(repalis auth token)" >> .env.local
```

Preselect scopes and store the token as a GitHub Actions secret without writing it to disk
```bash
repalis auth token --scope products:read --scope checkouts:write | gh secret set REPALIS_ACCESS_TOKEN
```

As an agent without a saved session, use your own access token; a human still approves the app token
```bash
REPALIS_ACCESS_TOKEN=<your access token> repalis auth token --org <org id> --scope events:write
```

Create a token for a specific organization
```bash
repalis auth token --org acme --scope events:write
```

## repalis auth logout

Sign out and remove saved sessions

```bash
repalis auth logout [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--sandbox` | `boolean` | Use the sandbox environment |
| `--production` | `boolean` | Use the production environment |
| `--all` | `boolean` | Remove every saved session |

**Examples**

Sign out, asking which session only if you have both
```bash
repalis auth logout
```

Remove every saved session
```bash
repalis auth logout --all
```
