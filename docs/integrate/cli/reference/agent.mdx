## repalis agent setup

Install the Repalis plugin, MCP server and skills for your coding agents

```bash
repalis agent setup [flags]
```

**Flags**

| Flag | Type | Description |
| --- | --- | --- |
| `--status` | `boolean` | Show what is set up without changing anything |
| `--confirm`, `-c` | `boolean` | Set up every detected agent without asking |
| `--force` | `boolean` | Reinstall even when an agent is already set up |
| `--client` | `choice` | Only set up this agent (choices: claude-code, codex, cursor) |
| `--skills` | `choice` | Also install the Repalis skills into .agents/skills of this directory (project) or your home directory (global), for agents without a Repalis plugin (choices: project, global) |

**Examples**

Detect Claude Code, Codex and Cursor, then choose what to set up
```bash
repalis agent setup
```

Show what is already set up
```bash
repalis agent setup --status
```

Only install the Repalis plugin for Claude Code
```bash
repalis agent setup --client claude-code
```

Install the Repalis skills into .agents/skills for any other agent
```bash
repalis agent setup --skills project
```

Set up every detected agent without asking, for scripts
```bash
repalis agent setup --confirm --json
```
