The official Python SDK provides fully typed synchronous and asynchronous clients for the Repalis API.

## Installation

The SDK requires Python 3.11 or later.

<Tabs>
  <Tab title="uv">
    ```bash Terminal
    uv add repalis-sdk
    ```
  </Tab>
  <Tab title="pip">
    ```bash Terminal
    pip install repalis-sdk
    ```
  </Tab>
</Tabs>

## Quickstart

Create an [organization access token](/integrate/oat), store it in `REPALIS_ACCESS_TOKEN`, and make your first request:

```python main.py
import os

from repalis.v2026_10 import Repalis

repalis = Repalis(os.environ["REPALIS_ACCESS_TOKEN"])

customer_state = repalis.customers.get_state_external("customer_external_id")
print(customer_state)
```

### Async client

Use `RepalisAsync` in asynchronous applications:

```python async_main.py
import asyncio
import os

from repalis.v2026_10 import RepalisAsync


async def main() -> None:
    repalis = RepalisAsync(os.environ["REPALIS_ACCESS_TOKEN"])
    customer_state = await repalis.customers.get_state_external(
        "customer_external_id"
    )
    print(customer_state)


asyncio.run(main())
```

The import path pins your client to the `2026-10` API version.

## Context managers

Both clients support context managers to close their HTTP connections automatically when the block exits.

For synchronous applications, use `Repalis` with `with`:

```python
import os

from repalis.v2026_10 import Repalis

with Repalis(os.environ["REPALIS_ACCESS_TOKEN"]) as repalis:
    customer_state = repalis.customers.get_state_external("customer_external_id")
    print(customer_state)
```

For asynchronous applications, use `RepalisAsync` with `async with`:

```python
import asyncio
import os

from repalis.v2026_10 import RepalisAsync


async def main() -> None:
    async with RepalisAsync(os.environ["REPALIS_ACCESS_TOKEN"]) as repalis:
        customer_state = await repalis.customers.get_state_external(
            "customer_external_id"
        )
        print(customer_state)


asyncio.run(main())
```

## Sandbox environment

The client uses production by default. Pass `environment="sandbox"` to use the isolated [sandbox environment](/integrate/sandbox):

```python
repalis = Repalis(
    os.environ["REPALIS_ACCESS_TOKEN"],
    environment="sandbox",
)
```
