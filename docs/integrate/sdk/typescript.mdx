The official TypeScript SDK provides a fully typed client for the Repalis API.

## Quickstart

Create an [organization access token](/integrate/oat) for server-side use, keep it out of browser bundles, store it in `REPALIS_ACCESS_TOKEN`, and make your first request:

```typescript icon="square-js" index.js
import { createRepalis } from "@repalis/sdk/2026-10";

const repalis = createRepalis({
  accessToken: process.env.REPALIS_ACCESS_TOKEN!,
});

const customerState = await repalis.customers.getStateExternal("customer_external_id");
console.log(customerState);
```

The import path pins your client to the `2026-10` API version.

## Sandbox environment

The client uses production by default. Pass `environment: "sandbox"` to use the isolated [sandbox environment](/integrate/sandbox):

```typescript
const repalis = createRepalis({
  accessToken: process.env.REPALIS_ACCESS_TOKEN!,
  environment: "sandbox",
});
```

[View the source code on GitHub](https://github.com/repaliscom/Repalis/tree/main/sdk/typescript).
