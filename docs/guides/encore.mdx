[Encore](https://encore.dev) is an open source backend framework for TypeScript with built-in infrastructure automation and observability. When you define services, databases, and APIs in code, Encore automatically provisions and manages the underlying infrastructure, both locally and in the cloud.

Because Encore defines infrastructure in code and provides built-in distributed tracing, AI coding assistants can both build and debug your backend end-to-end, including your Repalis integration. They can read the code to understand the full system, then inspect traces to diagnose exactly what happened when a checkout completes or a webhook arrives.

Consider following this guide while using the Repalis Sandbox Environment. This will allow you to test your integration without affecting your production data.

## Examples

- [With Encore](https://github.com/repaliscom/examples/tree/main/with-encore)

## Install the Repalis JavaScript SDK

To get started, install the Repalis JavaScript SDK and the webhook verification library:

```bash Terminal
npm install @repalis/sdk standardwebhooks
```

## Setting up Secrets

Encore has built-in secrets management that works consistently across local development and cloud environments.

### Repalis Access Token and Mode

To authenticate with Repalis, you need to create an access token and specify if it's production or sandbox mode. You can create an [organization access token from your organization settings](/integrate/oat).

Add it to Encore using the secrets manager:

```bash Terminal
encore secret set --type local REPALIS_ACCESS_TOKEN
encore secret set --type local REPALIS_MODE
```

### Repalis Webhook Secret

You'll need a webhook secret to verify incoming webhook events. We'll set this up in the webhook section below.

```bash Terminal
encore secret set --type local REPALIS_WEBHOOK_SECRET
```

When deploying to Encore Cloud, you'll set production secrets through the dashboard or CI/CD pipeline.

## Configuring a Repalis API Client

To interact with the Repalis API, create a client with `createRepalis` using Encore's secret management.

```tsx title="payments/repalis.ts"
import { createRepalis } from "@repalis/sdk/2026-10";
import { secret } from "encore.dev/config";

const REPALIS_MODE = secret("REPALIS_MODE");
const REPALIS_ACCESS_TOKEN = secret("REPALIS_ACCESS_TOKEN");

export const repalis = createRepalis({
  accessToken: REPALIS_ACCESS_TOKEN(),
  environment: REPALIS_MODE() as "sandbox" | "production",
});
```

Remember to set `REPALIS_MODE` as `production` when you're ready to switch to the production environment.

## Generating Repalis Checkout Sessions

Create a checkout endpoint that creates a Repalis checkout session and redirects the user.

```tsx title="payments/payments.ts"
import { api, APIError } from "encore.dev/api";
import { repalis } from "./repalis";

export const checkout = api.raw(
  { expose: true, path: "/checkout", method: "GET" },
  async (req, resp) => {
    const url = new URL(req.url!, `http://${req.headers.host}`);
    const productId = url.searchParams.get("product");

    if (!productId) {
      resp.writeHead(400);
      resp.end("Missing product query parameter");
      return;
    }

    try {
      const result = await repalis.checkouts.create({
        products: [productId],
        success_url: "https://your-app.com/confirmation?checkout_id={CHECKOUT_ID}",
      });

      resp.writeHead(302, { Location: result.url });
      resp.end();
    } catch (error) {
      console.error("[Repalis] Checkout error:", error);
      resp.writeHead(500);
      resp.end("Failed to create checkout session");
    }
  }
);
```

You can now create a checkout session by visiting `/checkout?product=YOUR_PRODUCT_ID`.

## Handling Repalis Webhooks

Repalis can send you events about various things happening in your organization. This is useful for keeping your database in sync with Repalis checkouts, orders, subscriptions, etc.

Configuring a webhook is simple. Head over to [**Settings → Webhooks**](https://repalis.com/to/dashboard/settings/webhooks) and click on the "Add Endpoint" button to create a new webhook.

### Tunneling webhook events to your local development environment

Encore runs your app locally with full infrastructure support. To receive webhooks during local development, you can use the [Repalis CLI](/integrate/cli/webhooks) to tunnel webhook events to your local environment.

```bash Terminal
repalis webhook listen http://localhost:4000/webhooks/repalis
```

Make sure to copy the webhook secret and set it using:

```bash Terminal
encore secret set --type local REPALIS_WEBHOOK_SECRET
```

### Add Webhook Endpoint

1. Point the Webhook to `your-app.com/webhooks/repalis`. This must be an absolute URL which Repalis can reach. If you use the Repalis CLI tunnel, it will handle this for you.
2. Select which events you want to be notified about. You can read more about the available events in the [Events section](/api-reference#webhooks).
3. Generate a secret key to sign the requests. This will allow you to verify that the requests are truly coming from Repalis.
4. Add the secret key to Encore:

```bash Terminal
encore secret set --type local REPALIS_WEBHOOK_SECRET
```

### Setting up the Webhook handler

Encore webhook handlers use `api.raw()` to access the raw request body, which is required for signature verification.

```tsx title="payments/payments.ts"
import { api } from "encore.dev/api";
import { secret } from "encore.dev/config";
import { Webhook } from "standardwebhooks";

const REPALIS_WEBHOOK_SECRET = secret("REPALIS_WEBHOOK_SECRET");

export const webhooks = api.raw(
  { expose: true, path: "/webhooks/repalis", method: "POST" },
  async (req, resp) => {
    // Read the raw request body
    const chunks: Buffer[] = [];
    for await (const chunk of req) {
      chunks.push(chunk);
    }
    const body = Buffer.concat(chunks).toString("utf-8");

    // Convert headers for standardwebhooks
    const headers: Record<string, string> = {};
    for (const [key, value] of Object.entries(req.headers)) {
      headers[key] = Array.isArray(value) ? value[0] : (value || "");
    }

    // Verify the webhook signature. Try Standard Webhooks first (secret as-is),
    // then Repalis's legacy HMAC (UTF-8 bytes of the full secret, including `whsec_`).
    const secret = REPALIS_WEBHOOK_SECRET().trim();
    let payload: any;
    try {
      payload = new Webhook(secret).verify(body, headers);
    } catch {
      try {
        const legacySecret = Buffer.from(secret, "utf-8").toString("base64");
        payload = new Webhook(legacySecret).verify(body, headers);
      } catch (error: any) {
        console.error("[Repalis] Invalid webhook signature:", error?.message);
        resp.writeHead(403);
        resp.end(JSON.stringify({ error: "Invalid signature" }));
        return;
      }
    }

    // Handle the payload
    switch (payload.type) {
      case "order.created":
        console.log("[Repalis] Order created:", payload.data.id);
        break;
      case "subscription.active":
        console.log("[Repalis] Subscription active:", payload.data.id);
        break;
      case "subscription.canceled":
        console.log("[Repalis] Subscription canceled:", payload.data.id);
        break;
      case "customer.state_changed":
        console.log("[Repalis] Customer state changed:", payload.data.id);
        break;
      default:
        console.log("[Repalis] Unhandled event:", payload.type);
    }

    resp.writeHead(200);
    resp.end(JSON.stringify({ received: true }));
  }
);
```

<Warning>
  Repalis webhook signatures use two key derivations depending on when the secret
  was generated. Repalis SDKs (version 1.0.0-alpha.19 and later) try both. If you
  verify with `standardwebhooks` directly: secrets created **on or after 8
  September 2026, 00:00 UTC** can be passed to `new Webhook()` as-is (`whsec_…`).
  Older Repalis secrets need the **entire** secret UTF-8 string base64-encoded
  first.
</Warning>

## Local Development

Start your Encore app:

```bash Terminal
encore run
```

Encore provides a local development dashboard at `localhost:9400` where you can:

- View distributed traces for all requests, including checkout redirects and webhook deliveries
- Inspect API calls between services
- Query local databases
- View logs and errors in real-time

This makes debugging payment flows straightforward since you can trace exactly what happens when a checkout completes or a webhook arrives.

## Deploying to Production

When you're ready to go live, deploy to Encore Cloud or your own cloud account:

```bash Terminal
git push encore
```

Encore automatically provisions all the infrastructure your app needs. Remember to:

1. Set production secrets in the Encore Cloud dashboard
2. Set the `REPALIS_MODE` secret to `"production"`
3. Update your webhook URL in Repalis to point to your production domain
4. Update `success_url` to your production URL
